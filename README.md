# fancy-storage
A BaaS service makes offline-first storage and cross-platform synchronization with so silky-smooth API that you barely notice it’s there.   

# APIs
## Initialization
In order to use the amazing feature this package provides, you need first to initialize it with two parameters:
- `api_key`: The API key you received from the [Fancy Storage](https://github.com/gcanoxl/fancy-storage), representing your app's identity.
- `sync_id`: The id your app creates for different users, representing each user's identity.

In a word, a project should have an `api_key` but multiple `sync_id` for different users.

`sync_id` can be generated by yourself or using `uuid` to let the package generate it for you.

```dart
void main() async {
    await WidgetsFlutterBinding.ensureInitialized();
    await FancyStorage.initialize(
        api_key: "YOUR_API_KEY",
        sync_id: "uuid", // or "YOUR_SYNC_ID"
    );
}
```

## Usage
In order to use FancyStorage, the first thing you need to do is to get a reference to it. If you are a flutter developer, you can use `FancyStorage.of(context)` to do so across the whole widget tree.

```dart
FancyStorage.of(context).put<T>("key", object<as T>);
FancyStorage.of(context).get<T>("key", {defaultValue: defaultValue<as T>, notWatch: false});
FancyStorage.of(context).remove("key");
```

### Use Key-Value Pair as List

```dart
FancyStorage.of(context).putAsList<T>("key", ["value1", "value2"]);
FancyStorage.of(context).getAsList<T>("key", {filter: (T value, int index) => true}, {defaultValue: defaultValue<as List<T>>, notWatch: false});
FancyStorage.of(context).remove("key");
FancyStorage.of(context).operateOnList<T>("key", (T value, int index) => T);
```

**operateOnList**

```dart 
FancyStorage.of(context).operateOnList<String>("todo_list", (value, index) {
    return value.toUpperCase(); // just an example
    // or
    return null; // delete it. the index will not be changed until the whole iteration is done.
});
```

## Example 
```dart
class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Builder(builder: (context) {
        final storage = FancyStorage.of(context);
        return Scaffold(
          appBar: AppBar(title: Text("Hello ${storage.get<String>('name' defaultValue: 'User')}")),
          body: Center(
            child: ElevatedButton(
              onPressed: () {
                storage.put<String>("name", "Peter");
              },
              child: Text("Save Greeting"),
            ),
          ),
        );
      }),
    );
  }
}
```
